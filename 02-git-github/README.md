# 🔀 Git & GitHub

Git provides the version-control foundation for application code, infrastructure code, documentation and automation. GitHub adds collaboration, pull requests, Actions, security and project workflows.

## Core concepts

```text
Working tree → Staging → Commit → Branch → Push → Pull Request → Review → Merge
```

## What I am practicing

- Repository and remote management
- Commits and meaningful commit messages
- Branching and merging
- Pull requests
- Rebase vs merge
- Tags and releases
- `.gitignore`
- GitHub Actions
- Repository security
