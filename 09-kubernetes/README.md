# ☸️ Kubernetes

Kubernetes orchestrates containerized workloads and introduces declarative management, scheduling, scaling and service discovery.

## Core objects

```text
Cluster
├── Control Plane
└── Worker Nodes
     ├── Pods
     ├── Services
     └── Controllers
```
