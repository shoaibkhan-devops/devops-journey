# 📈 Monitoring & Observability

Monitoring answers whether a system is healthy. Observability goes deeper: it helps explain why a system behaves the way it does.

## Three pillars

```text
Metrics + Logs + Traces
```

## Operational loop

```text
Collect → Correlate → Alert → Investigate → Remediate → Learn
```
