# 🛡️ DevSecOps

DevSecOps integrates security into the delivery lifecycle instead of waiting until the end.

## Secure pipeline

```text
Plan → Code → Build → Test → Scan → Package → Deploy → Monitor
              ↑       ↑       ↑
           SAST     SCA     IaC / Container Security
```

## Areas

- Secret detection
- Dependency scanning
- SAST / DAST concepts
- IaC security
- Container image scanning
- Identity and access
- Policy-as-code
- Secure supply chain

## Principle

The earlier a vulnerability is found, the cheaper and safer it is to fix.
