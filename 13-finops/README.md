# 💰 FinOps & Cloud Cost Optimization

Cloud engineering must include cost awareness. FinOps combines visibility, accountability and optimization.

## Cost lifecycle

```text
Measure → Understand → Optimize → Govern → Repeat
```

## Practical controls

- Tag resources
- Right-size VMs
- Remove idle resources
- Review storage tiers
- Use schedules for non-production workloads
- Set budgets and alerts
- Review reserved capacity where appropriate
- Allocate costs to teams / products

## DevOps connection

Infrastructure as Code makes cost optimization repeatable because the desired configuration can be reviewed and automated.
