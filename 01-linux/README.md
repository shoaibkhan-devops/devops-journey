# 🐧 Linux & System Administration

Linux is a core building block for modern DevOps, cloud engineering and platform operations. This section documents my journey from infrastructure administration toward Linux-based automation and troubleshooting.

## What I am learning

| Area | Topics |
|---|---|
| File system | `/`, `/etc`, `/var`, `/home`, `/tmp`, `/opt` |
| Users | users, groups, sudo, permissions |
| Processes | `ps`, `top`, `kill`, services |
| Networking | IP, routes, ports, DNS, SSH |
| Storage | disks, mounts, filesystem usage |
| Services | systemd, `systemctl`, `journalctl` |
| Automation | Bash, cron, environment variables |
| Troubleshooting | logs, connectivity, resource issues |

## Learning flow

```text
Linux fundamentals → Administration → Networking → Scripting → Troubleshooting → Automation
```
