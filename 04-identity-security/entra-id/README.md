# 👤 Microsoft Entra ID

Entra ID provides identity and access services for Azure and Microsoft cloud workloads.

## DevOps-related identities

- Human users
- Groups
- Service principals
- Managed identities
- Application identities

## Key concepts

```text
Authentication = Who are you?
Authorization  = What are you allowed to do?
```

## DevOps use cases

- Pipeline service connections
- Workload identities
- RBAC assignments
- Secure application authentication

Prefer short-lived / workload-based identity patterns over storing long-lived credentials in source code.
