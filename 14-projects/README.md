# 🚀 Hands-on DevOps Projects

This section will become the portfolio layer of the repository: real projects, architecture decisions, code, screenshots, troubleshooting and lessons learned.

## Planned projects

### 01 — Azure Infrastructure with Terraform
Provision resource groups, storage and networking through Infrastructure as Code.

### 02 — Terraform Remote State
Store Terraform state securely in Azure Storage and document the backend design.

### 03 — Azure Network Foundation
Build VNet, subnets and NSGs with a repeatable Terraform design.

### 04 — Azure VM Deployment
Provision and secure a Linux VM with Terraform.

### 05 — Terraform CI/CD
Validate and plan Terraform changes through a pull-request pipeline, then deploy through an approved stage.

### 06 — Azure Landing Zone Lab
Model management groups, governance, policies and workload subscriptions.

### 07 — Containerized Application
Build, scan and run a Docker image.

### 08 — Kubernetes Deployment
Deploy the containerized application using Kubernetes and Helm.

## Project template

Each project should contain:

```text
README.md
architecture.png
source-code/
screenshots/
troubleshooting.md
```

Each README should explain **what was built, why it was designed that way, how to deploy it, how it was secured, what failed, and what was learned.**
