# 📊 Azure Monitoring

Monitoring turns infrastructure state into operational signals and alerts.

## Core services

- Azure Monitor
- Metrics
- Log Analytics Workspace
- Activity Log
- Alerts
- Application Insights

## Observability model

```text
Metrics + Logs + Traces
          ↓
       Analysis
          ↓
        Alert
          ↓
       Action
          ↓
   Incident / Automation
```

## Practical examples

- VM CPU / memory signals
- Disk utilization
- Failed sign-ins
- Network connectivity
- Resource changes
- Service health
