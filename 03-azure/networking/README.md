# 🌐 Azure Networking

Networking is the foundation that connects workloads, users, services and security controls.

## Core building blocks

```text
VNet
 ├── Subnet
 │    ├── NSG
 │    └── Workloads
 ├── Private / Public IP
 ├── Route tables
 └── Connectivity
      ├── VNet Peering
      ├── VPN
      └── ExpressRoute concepts
```

## Concepts to practice

- CIDR and subnetting
- DNS
- Routing
- NAT
- NSG evaluation
- Public vs private endpoints
- Hub-and-spoke
- Private connectivity

## DevOps connection

Network design becomes much more reliable when it is defined and reviewed as code.
