# ☁️ Microsoft Azure

Azure is the primary cloud platform in my DevOps journey. This section moves from individual resources toward secure, governed and automated cloud architecture.

## Core areas

- Compute: Virtual Machines
- Networking: VNet, Subnets, NSG, VPN, Load Balancer, Application Gateway, Bastion
- Storage: Storage Accounts, Blob, Files
- Monitoring: Azure Monitor, Log Analytics, alerts
- Governance: RBAC, Policy, tags, cost management

## Architecture mindset

Do not ask only **"Can I create this resource?"** Ask **"How should this resource be secured, governed, observed, recovered and automated?"**
